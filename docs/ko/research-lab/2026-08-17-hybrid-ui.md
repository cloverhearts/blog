새로운 인터페이스가 등장할 때마다 이전 방식은 곧 사라질 것처럼 보입니다. 명령어 뒤에 GUI가 왔을 때도 그랬고, 자연어로 프로그램을 다룰 수 있게 된 지금도 비슷한 예측이 나옵니다.

하지만 실제 변화는 대체보다 재배치에 가까운 경우가 많습니다. AI 시대의 GUI도 없어지기보다 역할이 달라질 가능성이 큽니다.

## GUI는 선택지를 보여 준다

GUI의 장점은 사용자가 기억하지 않아도 된다는 데 있습니다. 화면에 보이는 버튼과 메뉴를 통해 가능한 행동을 발견할 수 있고, 현재 상태도 비교적 쉽게 확인할 수 있습니다.

약점도 분명합니다. 여러 화면을 오가며 같은 조작을 반복해야 하고, 복잡한 목표를 작은 클릭 단위로 쪼개야 합니다. 사용자가 하고 싶은 일보다 프로그램이 정한 순서를 따라가게 되는 순간도 많습니다.

## LUI는 의도를 바로 말하게 한다

LUI는 언어 기반 사용자 인터페이스를 뜻합니다. 사용자가 메뉴를 찾는 대신 원하는 결과를 문장으로 요청합니다. 여러 단계를 한 번에 묶을 수 있고 익숙한 말로 시작할 수 있다는 점이 강력합니다.

다만 빈 입력창은 가능한 기능을 보여 주지 않습니다. 요청이 모호하면 결과도 흔들리고, AI가 무엇을 바꾸었는지 한눈에 파악하기 어려울 수 있습니다. 자연어는 표현의 장벽을 낮추지만 판단의 책임까지 없애 주지는 않습니다.

## 결국 남는 것은 Hybrid UI

두 방식의 장점을 합친 화면을 Hybrid UI라고 부를 수 있습니다. 사용자는 말로 목표를 전달하고, 화면에서 범위와 결과를 확인하며, 필요한 부분만 직접 조정합니다.

예를 들어 긴 문서를 다듬을 때는 AI에게 전체 구조 정리를 요청할 수 있습니다. 이후 변경된 문단을 화면에서 비교하고, 마음에 들지 않는 부분은 직접 선택해 수정합니다. 언어는 작업을 시작하고 화면은 작업을 통제합니다.

| 상황 | 더 적합한 방식 |
| --- | --- |
| 무엇을 할 수 있는지 탐색할 때 | GUI |
| 반복되는 여러 단계를 실행할 때 | LUI |
| 결과를 비교하고 미세 조정할 때 | GUI |
| 목표는 분명하지만 방법을 모를 때 | LUI와 GUI의 결합 |

AI 시대의 좋은 화면은 버튼을 모두 지운 화면이 아닐 것입니다. 사용자가 의도를 말할 수 있고, AI의 행동을 볼 수 있으며, 언제든 개입할 수 있는 화면에 가까울 것입니다. GUI의 미래는 사라짐이 아니라 조작판에서 검토판과 협업 공간으로의 변화라고 생각합니다.
