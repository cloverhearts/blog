# Open Design Staging Area

This directory may hold Open Design exports that are being reviewed for the
normal blog design. It is source workspace, not a production build input.

Before promoting an export:

- compare it with the root `DESIGN.md` scope and protected decisions;
- review provenance, license, fonts, imagery, and third-party trademarks;
- remove generated placeholders and unused assets;
- translate approved design tokens into the blog application's maintained style
  source;
- verify that no remote dependency, secret, local path, or Open Design runtime
  requirement enters the production build.

Managed-page Open Design work belongs inside that page package, not here.
