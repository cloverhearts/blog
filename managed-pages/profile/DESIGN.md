# Profile page design

This managed document is independent of the root blog `DESIGN.md`. It uses a
single readable column, a visible `h1`, and the required floating return link.

- Language: Korean source variant.
- Source order is the reading and keyboard order.
- Contact links are ordinary HTTPS or `mailto` destinations.
- No blog header, footer, taxonomy, or post-card chrome is inherited.
- Print hides the return control and keeps the article text.
- The page stays readable without JavaScript.
